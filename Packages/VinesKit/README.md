# VinesKit

Лианы, свисающие с верхнего края экрана. Они покачиваются, провисают по наклону телефона, раскачиваются от тряски и бряцают звеньями. Пальцем лиану можно раскачать, а резким смахом — сорвать.

Слой лиан не перехватывает касания: интерфейс под ним работает как обычно, даже когда палец проходит по лиане. Бэкенд и разрешения не нужны. Внешний вид, сезонные паки и звуки приходят с CDN.

- iOS 15+, Swift 6 (strict concurrency), только фреймворки Apple — без сторонних зависимостей.
- Пакет независим от MascotKit, их можно подключать по отдельности или вместе.

## Быстрый старт

1. Xcode → File → Add Package Dependencies → Add Local… → папка `Packages/VinesKit` (или по URL репозитория).
2. Один раз при старте укажите папку CDN, где лежит `vines.json`.
3. Повесьте `.hangingVines()` на корневую вьюху экрана.

```swift
import VinesKit

@main
struct MyApp: App {
    init() {
        Vines.contentURL = URL(string: "https://cdn.example.com/fun/")
    }
    var body: some Scene {
        WindowGroup { HomeView().hangingVines() }
    }
}
```

Это всё: при открытии экрана пакет скачает `vines.json`, выберет пак по сезону и весу, подгрузит картинки и звуки и покажет лианы.

## Публичный API

В пакете три публичные точки входа: `Vines.contentURL`, `.hangingVines(...)` и `.vineOcclusion()`. Всё остальное — внутреннее.

### `Vines.contentURL`

```swift
public enum Vines {
    public static var contentURL: URL? { get set }
}
```

Базовый адрес CDN — папка, относительно которой ищутся `vines.json`, картинки и звуки. Задаётся один раз на главном потоке до первого показа лиан, обычно в `init()` приложения. Адрес должен заканчиваться на `/`, иначе последний компонент пути будет отброшен при сборке относительных ссылок.

Подходит и `file://` URL — удобно для локальной проверки контента.

### `.hangingVines(isActive:configFile:refreshID:onCleared:)`

```swift
func hangingVines(isActive: Bool = true,
                  configFile: String = "vines.json",
                  refreshID: Int = 0,
                  onCleared: (() -> Void)? = nil) -> some View
```

Накладывает слой лиан поверх вьюхи на весь экран, включая safe area.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `isActive` | `true` | Можно ли показывать лианы. Пока `false`, конфиг не грузится и ничего не рисуется. Переключили в `true` — начнётся загрузка. Переключили в `false` при показанных лианах — они скрываются. |
| `configFile` | `"vines.json"` | Имя конфига относительно `Vines.contentURL`. Можно указать другой файл, например для A/B-теста. |
| `refreshID` | `0` | Счётчик повторного показа. Увеличьте его, чтобы показать лианы снова (см. ниже). |
| `onCleared` | `nil` | Вызывается один раз, когда пользователь сорвал все лианы. После этого слой плавно исчезает. |

**Как работает `refreshID`:**
- лианы уже на экране — текущий пак мгновенно перезапускается с новой раскладкой, конфиг и картинки повторно не грузятся;
- лиан нет (сорваны или не показывались) — выполняется обычная загрузка, но `cooldownMinutes` пропускается. Выключатель `enabled` и системная настройка «Уменьшение движения» по-прежнему учитываются.

**Когда лианы не показываются:**
- `isActive == false`;
- в системе включено «Уменьшение движения» (Accessibility → Reduce Motion);
- нет ни CDN, ни кэша прошлой удачной загрузки конфига;
- `enabled: false` в конфиге, ещё не прошёл `cooldownMinutes` или нет ни одного активного пака;
- у пака только картинки (`images` без `glyphs`), и ни одна из них не загрузилась.

**Пауза.** Анимация, датчики и звук останавливаются, когда вьюха ушла с экрана или приложение не активно, и продолжаются при возврате.

### `.vineOcclusion()`

```swift
func vineOcclusion() -> some View
```

Помечает вьюху как важный элемент интерфейса. Лиана, которая проходит поверх помеченной вьюхи, становится полупрозрачной (`overlapOpacity` из пака), чтобы не мешать читать. Вешайте на карточки, кнопки, таббар — на всё, что не должно перекрываться.

Модификатор только сообщает рамку вьюхи и не меняет её вид и поведение. Работает на любой глубине иерархии под `.hangingVines()`.

### Пример из демо-приложения

```swift
struct ContentView: View {
    @State private var vinesRefreshID = 0
    @State private var hasUserScrolled = false

    var body: some View {
        HomeView(
            onRefresh: { vinesRefreshID += 1 },        // pull-to-refresh показывает лианы заново
            onFirstScroll: { hasUserScrolled = true }  // лианы появляются после первого скролла
        )
        .hangingVines(isActive: hasUserScrolled, refreshID: vinesRefreshID)
        .mascot()
    }
}

balanceCard.vineOcclusion()   // лианы над балансом — полупрозрачные
```

## Взаимодействие

| Действие | Что происходит |
|---|---|
| Провести пальцем по лиане | Звенья в радиусе ~26 pt от пальца получают импульс, лиана раскачивается |
| Резкий смах по лиане | Если скорость пальца выше `tearSpeed`, лиана срывается и улетает с этой скоростью, срабатывает лёгкая вибрация (`haptic`) |
| Наклон телефона | Лианы провисают по направлению силы тяжести, поворот интерфейса учитывается |
| Тряска | Инерционный толчок: звенья двигаются с разной фазой, кончик отскакивает при натяжении, качание плавно затухает |
| Поворот и тряска | Звуки бряцания: чем резче движение, тем громче и чаще. Мелкое дрожание рук отсекается, сильная тряска (от 1 g) звучит сразу |

Свайп ловится распознавателем на окне, который не отменяет касания. Поэтому скролл, кнопки и жесты приложения работают как раньше.

В симуляторе нет датчиков: там видно только покачивание и смахивание, а наклон и тряску проверяйте на устройстве.

## Контент на CDN — `vines.json`

Изменения видны при следующем открытии экрана, релиз не нужен.

```json
{
  "enabled": true,
  "cooldownMinutes": 0,
  "forcePack": null,
  "packs": [
    {
      "id": "matrix",
      "glyphs": ["6", "7"],
      "flicker": true,
      "colors": ["#12B33A"],
      "headColor": "#9EFF9E",
      "glow": "#12B33A99",
      "length": [0.07, 0.24],
      "spacing": 0.12,
      "sound": { "enabled": true, "volume": 0.8, "files": ["sounds/vines/matrix_1.wav"] }
    },
    {
      "id": "autumn",
      "weight": 2,
      "from": "09-01",
      "to": "11-15",
      "glyphs": ["🍂", "🍁", "🌰"],
      "head": ["🍁", "🌰"],
      "itemEvery": 2,
      "thread": "#8A5A2B",
      "threadWidth": 1.5
    }
  ]
}
```

### Корень

| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `enabled` | Bool | `true` | Выключатель всех лиан |
| `cooldownMinutes` | число | `0` | Показывать не чаще раза в N минут. `0` — при каждом открытии |
| `forcePack` | String | — | id пака, который показать всегда, в обход сезона и весов. Для демо и проверки |
| `packs` | массив | `[]` | Паки. Пак с ошибкой в JSON (например, без `id`) пропускается, остальные работают |

### Как выбирается пак

1. Есть `forcePack` и такой пак в списке — берётся он.
2. Иначе из паков с `weight > 0`, у которых сейчас сезон (или сезона нет), выбирается случайный с учётом весов.

В отличие от MascotKit, сезонные паки не важнее обычных — всё решают веса. Чтобы в сезон показывался почти только он, дайте ему большой `weight`.

### Пак

Обязателен только `id`.

**Выбор и сезон**

| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `id` | String | — | Имя пака |
| `weight` | число | `1` | Вес при случайном выборе. `0` — только через `forcePack` |
| `from`, `to` | `"MM-DD"` | — | Сезон, повторяется каждый год. Может переходить через Новый год: `"12-15"` … `"01-10"` |

**Что висит**

| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `glyphs` | [String] | `["6","7"]` | Символы-звенья: буквы, цифры, эмодзи. Если заданы `images`, а `glyphs` нет, символов не будет |
| `images` | [String] | `[]` | Картинки-звенья. Путь относительно `vines.json` или полный URL |
| `head` | [String] | `[]` | Символы на кончике. Каждой лиане достаётся свой |
| `headImages` | [String] | `[]` | Картинки на кончике |
| `itemEvery` | Int | `1` | Звено на каждом N-м сегменте: `1` — сплошь, `3` — реже. `0` — только нить и кончик |

**Как выглядит**

| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `scale` | число | `1.35` | Общий масштаб звеньев, кончика и нити. Ограничен 0.6…2 |
| `glyphSize` | [min, max] | `[10, 17]` | Размер звена в pt до `scale`. У каждой лианы — случайный из диапазона |
| `headSize` | число | — | Размер кончика в pt до `scale`. Нет — как у звеньев лианы |
| `colors` | [hex] | `["#12B33A"]` | Палитра символов, `#RRGGBB` или `#RRGGBBAA` |
| `headColor` | hex | первый из `colors` | Цвет символа на кончике |
| `monospaced` | Bool | `true` | Моноширинный шрифт. `false` — скруглённый |
| `flicker` | Bool | `false` | Мерцание «как в Матрице»: символы меняются, звенья у корня бледнее |
| `glow` | hex | — | Цвет свечения вокруг звеньев. В облегчённом режиме выключено |
| `thread` | hex | — | Цвет нити между звеньями. Нет — нити не видно |
| `threadWidth` | число | `1.2` | Толщина нити в pt, умножается на `scale` |
| `overlapOpacity` | 0…1 | `0.38` | Непрозрачность лианы поверх вьюх с `.vineOcclusion()`: `0` — невидима, `1` — как обычно |

**Сколько и какой длины**

| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `count` | Int | ширина / 34, но не меньше 6 | Сколько лиан. Верхняя граница — 18 |
| `spacing` | 0.03…1 | — | Минимальный промежуток между лианами как доля ширины экрана: `0.12` — 12%. Чем больше, тем меньше лиан |
| `length` | [min, max] | `[0.1, 0.34]` | Длина лианы как доля высоты экрана |

Итоговое число лиан — минимум из `count`, того, что позволяет `spacing`, и того, что помещается по ширине при текущем размере звеньев. В облегчённом режиме — ещё на 40% меньше. В цепочке не больше 28 звеньев (20 в облегчённом режиме).

**Поведение**

| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `sway` | число | `1` | Сила покачивания от «ветра» |
| `tearSpeed` | pt/с | `1100` | Скорость смаха, нужная для отрыва. Меньше — срывать легче |
| `haptic` | Bool | `true` | Вибрация при отрыве |

**Звук — `sound`**

| Поле | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `enabled` | Bool | `true` | Включить звуки пака |
| `volume` | 0…1 | `1` | Громкость |
| `files` | [String] | `[]` | Варианты бряцания, пути относительно `vines.json` или полные URL. Играют вперемешку |

Встроенных звуков нет: без `files` пак беззвучный. Недоступный файл пропускается. Звук уважает беззвучный режим и не прерывает музыку. Если приложение само настроило аудиосессию, пакет её не трогает.

### Картинки

- PNG @3x с прозрачным фоном. Точка подвеса — сверху по центру.
- Кэшируются навсегда по адресу. **Новую картинку кладите под новым именем**, а не перезаписывайте старую: иначе у пользователей останется старая.

### Загрузка и кэш

1. `vines.json` скачивается с CDN. При успехе он сохраняется в кэш.
2. CDN недоступен — берётся кэш прошлой удачной загрузки.
3. Нет ни того ни другого — лианы не показываются. Встроенного конфига в приложении нет.

Картинки и звуки качаются параллельно и тоже кэшируются. Вся работа с сетью, диском и JSON идёт вне главного потока.

## Отладка

Аргументы запуска (Edit Scheme → Run → Arguments):

| Аргумент | Что делает |
|---|---|
| `-CDNBaseURL <url>` | Подменить папку CDN, например `file:///Users/me/sberkids-cdn/` |
| `-FunLiteMode YES` / `NO` | Принудительно включить или выключить облегчённый режим |
| `-LaunchDiagnostics YES` | Писать в журнал метрики первых 12 секунд: готовность первого кадра, p95 ожидания расчёта, интервалы кадров, пропущенные такты. Подсистема `AlfaKids.Performance`, категория `Vines` |

Чтобы проверить конкретный пак, задайте `forcePack` и `cooldownMinutes: 0`.

## Как устроен пакет

| Файл | Что внутри |
|---|---|
| `HangingVines.swift` | Публичный API: `Vines`, `.hangingVines()`, `.vineOcclusion()`; ловец свайпов на окне; `VineField` — координатор кадров |
| `VinesConfig.swift` | Разбор `vines.json`: `VinesConfig`, `VinePack`, `VineSoundConfig`, выбор пака |
| `VinesConfigStore.swift` | Загрузка конфига, cooldown, подготовка картинок и звуков пака |
| `CDNContent.swift` | Сеть, дисковый кэш, сезоны |
| `VineSimulation.swift` | Actor симуляции: раскладка лиан, касания, отрыв, датчики, готовый кадр |
| `VinePhysics.swift` | Физика цепочек: инерция, ограничение длины, отскок кончика |
| `VineLayerView.swift` | Отрисовка на `CALayer` и атлас спрайтов `VineSpriteAtlas` |
| `VineMotion.swift`, `VineMotionSample.swift` | Core Motion: гравитация, ускорение, вращение |
| `VineSoundResponse.swift`, `VineChainSound.swift` | Когда и как громко бряцать; actor проигрывания |
| `DevicePerformance.swift` | Облегчённый режим |

Поток кадра:

```
CADisplayLink → VineField (главный поток)
    → VineSimulation (actor): касания + датчики → VinePhysics
    → VineFrame (неизменяемый) → VineLayerView: позиции, повороты, прозрачность слоёв
                               → VineChainSound (actor): звук
```

- **Физика вне главного потока.** Массивами физики владеет только actor `VineSimulation`. Главный поток передаёт в него касания и данные датчиков значениями и получает готовый `VineFrame`.
- **Не больше одного запроса кадра одновременно.** Если расчёт не успел, такты экрана пропускаются, а не копятся в очередь. Номер поколения отбрасывает устаревшие кадры после паузы или перезапуска.
- **Каждая лиана — независимая цепочка.** Шаг физики 1/120 с, до 4 проходов натяжения. Лианы не сталкиваются и не передают импульс друг другу.
- **Отрисовка на постоянных слоях.** Слои создаются один раз; на кадре меняются только положение, поворот и прозрачность. Символы и картинки заранее растрируются в общий атлас вне главного потока. Нити — переиспользуемые `CAShapeLayer`, контуры для них строятся в actor.

## Производительность и слабые устройства

- Отрисовка не чаще 60 кадров в секунду.
- Если два кадра подряд не уложились в бюджет, решатель на время снижает число проходов натяжения, а накопленные шаги отбрасывает.
- Датчики работают только пока лианы видны и экран активен; они читаются по такту кадра, без колбэка на каждое измерение.
- Аудиоплееры создаются при первом звуке.

**Облегчённый режим** включается на телефонах с 2 ГБ памяти (iPhone 6s/7/SE — у них последняя iOS 15) и при энергосбережении:
- 30 кадров в секунду;
- на 40% меньше лиан;
- до 20 звеньев в цепочке;
- без свечения;
- 3 прохода натяжения вместо 4.

## Тесты и замер

Тесты: схема `VinesKit` в Xcode или `xcodebuild test -scheme VinesKit -destination 'platform=iOS Simulator,name=iPhone 17'`. Проверяются:
- разбор конфига;
- загрузка вне главного потока;
- независимость цепочек и конечность физики при сильной тряске;
- переиспользование слоёв;
- 360 кадров с максимальной плотностью, непрерывной тряской и сменой размера.

Замер физики на CPU (без отрисовки, звука и датчиков) — сцены из 12 нитей по 18 звеньев, в покое и при тряске, медиана трёх прогонов по 2400 шагов. Из корня репозитория:

```sh
swiftc -O Packages/VinesKit/Sources/VinesKit/VinePhysics.swift Packages/VinesKit/Benchmarks/PhysicsBenchmark.swift -o /tmp/vines-physics-bench
/tmp/vines-physics-bench
```

Это замер на Mac, он не заменяет измерение FPS на iPhone.
