# VinesKit

Лианы, свисающие с верхнего края экрана: качаются, их можно раскачать пальцем и сорвать резким смахом. Касания проходят сквозь лианы, интерфейс под ними работает как обычно. iOS 15+, Swift 6 (strict concurrency), только фреймворки Apple — без сторонних зависимостей.

## Подключение

```swift
import VinesKit

@main
struct MyApp: App {
    init() {
        Vines.contentURL = URL(string: "https://cdn.example.com/fun/")   // папка с vines.json и картинками
    }
    var body: some Scene {
        WindowGroup { HomeView().hangingVines() }
    }
}
```

Параметры: `.hangingVines(isActive:configFile:bundledFallback:onCleared:)`. По умолчанию конфиг — `vines.json`, запасной в бандле приложения — `vines_default.json`.

## Контент с CDN — `vines.json`

Пак лиан выбирается по сезону и весу. Есть принудительный выбор `forcePack` и интервал между показами `cooldownMinutes`. В каждом паке можно менять:
- символы или картинки звеньев и кончика;
- нить, цвета, свечение;
- количество и длину лиан;
- покачивание и силу смаха для отрыва.

Готовые паки: матрица, осень, Хэллоуин, Новый год. Полное описание полей — в `cdn/README.md` репозитория.

Порядок загрузки: CDN → кэш прошлого запуска → запасной JSON из бандла. Картинки скачиваются до показа и кэшируются на диск.

## Отладка

Аргумент запуска `-CDNBaseURL <url>` подменяет папку CDN.

## Слабые устройства

На телефонах с 2 ГБ памяти (iPhone 6s/7/SE — у них последняя iOS 15) и при энергосбережении включается облегчённый режим: 30 кадров в секунду, на 40% меньше лиан, без свечения, физика считается короче. Анимация останавливается, когда приложение свёрнуто или экран закрыт другим.

Аргумент запуска `-FunLiteMode YES` / `NO` принудительно включает или выключает облегчённый режим.
