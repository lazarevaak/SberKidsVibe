# MascotKit

Маскот, который живёт поверх интерфейса: ходит по карточкам, прыгает между ними, реагирует на наклон, тряску, зарядку и события приложения. Его можно схватить и кинуть.

Касания ловит только сам маскот: интерфейс под ним работает как обычно. Бэкенд и разрешения не нужны. Контент, поведение и триггеры приходят с CDN. iOS 15+, Swift 6 (strict concurrency), только фреймворки Apple — без сторонних зависимостей.

## Подключение

Swift Package: в Xcode → File → Add Package Dependencies → Add Local… (или по URL репозитория).

```swift
import MascotKit

@main
struct MyApp: App {
    init() {
        Mascot.contentURL = URL(string: "https://cdn.example.com/fun/")   // папка с pet.json и картинками
    }
    var body: some Scene {
        WindowGroup { HomeView().mascot() }
    }
}
```

## Разметка интерфейса

```swift
avatar
    .mascotHome()                                    // домик: сюда уходит, отсюда выпрыгивает
    .mascotTrigger("avatar", .longPress(), .toggle)  // долгое нажатие — позвать / отпустить

card.mascotSurface()                                 // по верхнему краю можно ходить
tabBar.mascotSurface("tabbar", occludesBelow: true)  // всё, что под ней, скрыто

qrIcon.mascotTrigger("qr", .tap(count: 3), .summon)  // пасхалка
```

Триггеры добавляются к собственным жестам вьюхи и не ломают их. Маскот выпрыгивает из той вьюхи, на которой сработал триггер.

| Жесты | Действия |
|---|---|
| `.tap(count:)`, `.longPress(duration:)` | `.summon`, `.toggle`, `.sendHome`, `.celebrate`, `.event(.topUp)`, `.react("ключ")` |

## События из бизнес-логики

```swift
Mascot.send(.topUp)         // пополнение — маскот прибегает и радуется
Mascot.perform(.summon)
```

## Когда появляется сам

- первый вход за день — спускается на ниточке;
- случайно при открытии, с шансом из конфига;
- тряска телефона — падает сверху;
- подключение зарядки.

Уходит домой, если долго нет внимания, или если его выкинуть за экран.

## Управление с CDN — `pet.json`

Все поля необязательны:
- триггеры: `onShake`, `onEvents`, `onCharging`, `firstOpenOfDay`, `randomChance`;
- время в гостях: `stayMinutes`;
- веса поведения: `behaviors`;
- реплики: `phrases`;
- сезонные костюмы: `skins`;
- переопределение триггеров на вьюхах по id:

```json
"triggers": {
  "avatar":  { "gesture": "doubleTap", "action": "summon" },
  "balance": { "enabled": false }
}
```

Порядок загрузки: CDN → кэш прошлого удачного запуска. В приложение ничего не зашито — ни реплик, ни звуков, ни персонажа: нет ни CDN, ни кэша — маскот просто не появляется. Имя конфига можно поменять: `.mascot(configFile:)`.

## Реплики, звуки и анимации — `reactions`

В `pet.json` одна таблица «событие → реакция»: что сказать (и с какой вероятностью), какой звук, какую анимацию, как часто повторять. Свои события тоже можно завести из конфига и повесить на любую вьюху:

```json
"reactions": {
  "tap":    { "say": ["Хи-хи!", "Щекотно!"], "sayChance": 0.5, "sound": ["sounds/tap.wav"] },
  "topUp":  { "say": ["Ура, денежки!"], "sound": ["sounds/tada.wav"], "animation": "celebrate" },
  "secret": { "say": ["Ты нашёл тайник!"], "sound": ["sounds/magic.wav"], "animation": "dance" }
}
```
```swift
tile.mascotTrigger("tile", .tap(count: 3), .react("secret"))
```

**Гарантированные реплики с лимитом за визит.** Например, рассказать о новой функции: первые 3 тапа за визит маскот говорит её, дальше — обычные реплики; ушёл и позвали снова — опять 3 раза.

```json
"tap": { "say": [ "Хи-хи!", "Щекотно!",
  { "text": "А ты уже поставил цель в Копилках?", "maxPerVisit": 3, "first": true, "duration": 4.5 } ] }
```

Окно реплики настраивается там же: `"bubble": { "fontSize": 14, "maxWidth": 240, "maxLines": 3, "background": "#FFF4D6", "duration": 3 }`.

У реакции целиком тоже есть `maxPerVisit` — например, реагировать на тряску не больше двух раз за визит.

Звуки качаются с CDN в фоне и кэшируются, проигрыватели создаются один раз. Звук всегда — ответ на действие, сам по себе не играет. В беззвучном режиме молчит и не прерывает музыку: если приложение само не настраивало аудиосессию, пакет ставит `.ambient`, свои настройки приложения не трогает. Общие громкость и выключатель — `sounds: { "enabled", "volume" }`.

## Свой персонаж — без кода

Персонаж описывается данными: картинки-детали + `character.json` (где деталь крепится, вокруг чего вращается, как двигается в каждом состоянии, какие картинки на какие эмоции). Физика, поведение, реплики, звуки и триггеры — общие для всех персонажей. Так можно сделать хоть зверька, хоть машинку:

```json
"characters": [
  { "id": "monkey", "path": "characters/monkey/character.json" },
  { "id": "car", "path": "characters/car/character.json", "weight": 0 },
  { "id": "snowman", "path": "characters/snowman/character.json", "from": "12-15", "to": "01-10" }
],
"forceCharacter": "car"
```

Свои анимации тоже задаются в `character.json` (раздел `animations`) и вешаются на любое событие через `reactions` → `animation` или в `behaviors` с весом — например, на тап персонаж может танцевать вместо прыжка.

Сезонный персонаж важнее круглогодичного, среди равных выбирается по весам. Размер — общий `"scale"` (по умолчанию 0.75) или свой `scale` у персонажа: уменьшается и картинка, и область касания, и физика. Если персонаж не загрузился (нет сети и кэша, не хватает картинки), маскот не появляется — лучше никак, чем «с дырками». Формат `character.json` — в [README CDN-репозитория](https://github.com/karablik27/sberkids-cdn#readme).

## Журнал и проверка контента

Пакет пишет в системный журнал (подсистема `MascotKit`): в консоли Xcode или в приложении «Консоль» на Mac — в том числе с подключённого телефона — достаточно отфильтровать по `MascotKit`.

После загрузки конфига и персонажа пакет проверяет контент и пишет понятные подсказки:
- **предупреждения** — когда что-то точно не сработает: реакция или behaviors ссылаются на несуществующую анимацию, опечатка в состоянии движения детали (`wlak` вместо `walk`), `forceCharacter` / `forceSkin` нет в списке, неизвестный жест или действие в `triggers`, неизвестная эмоция или эффект у анимации;
- **заметки** — когда всё работает, но стоит знать: своё событие, которое сработает только от триггера `.react("…")`, у детали нет картинки для какой-то эмоции (будет обычная).

Опечатка в конфиге не ломает маскота — он просто не сделает то, что описано с ошибкой, а в журнале будет сказано, что именно поправить.

## Отладка

Аргументы запуска:
- `-CDNBaseURL <url>` — подменить папку CDN;
- `-MascotAlwaysAppear YES` — показывать маскота при каждом запуске.

## Слабые устройства

На телефонах с 2 ГБ памяти (iPhone 6s/7/SE — у них последняя iOS 15) и при энергосбережении включается облегчённый режим: 30 кадров в секунду вместо 60. Маскот рисуется одним растровым слоем. Анимация останавливается, когда приложение свёрнуто или экран закрыт другим. На iOS 15 положение карточек при скролле досчитывается по их скорости, чтобы маскот не отставал.

Аргумент запуска `-FunLiteMode YES` / `NO` принудительно включает или выключает облегчённый режим.
